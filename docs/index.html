01

Productivity trend

Productivity is LT trips ÷ DR trucks onsite. At 1.0, each rented truck ran one trip a day.

How it's counted
Trucks onsite: "By Day" check-ins on the On Site Registration sheet, excluding Expired and No Show. The same plate checked in twice on one day counts once; on two days it counts twice (truck-days). LT trips: each LT counted once on the day its first leg left a DC, billed "By Day", from the SOC-LM, FM-SOC and SOC-SOC trackers. Empty LT and working hours use finished LTs only (every leg arrived); working hours run from the truck reaching its first station to reaching its last.

03

Empty pickups and deliveries

Legs that should carry parcels but ran with none, across every cost type (not only DR).

How it's counted
Pickup: an FM hub → SOC leg is empty when the truck reached the SOC with 0 parcels loaded at any hub since it left the last SOC. Delivery: a SOC → LM hub run is empty when 0 parcels were loaded at the SOC and 0 unloaded at its hubs (checked once the run has arrived). SOC → FM and LM → SOC legs, "Not Depart" legs, and duplicate rows across trackers are left out. The Vehicle filter doesn't apply here.
