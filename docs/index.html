    Vendor Productivity — Trips per Onsite Daily Rent Unit

    DR = Daily Rent = Cost Type "By Day", applied consistently on both sides of this ratio. Daily Onsited = count of check-ins on the [29309] On Site Registration sheet with cost_type = "By Day" and arrival_status not "Expired" or "No Show" — i.e. vehicles that actually showed up, whether On Time, Late, or still Pending check-out. Deduped by distinct Nopol (plate number) + Vendor per day — if the same physical vehicle gets registered more than once on the same day, it counts once. Rows without a Nopol filled in count individually. Daily LT (using DR) = first-leg trips that had actually departed, billed Cost Type "By Day". Productivity = Daily LT ÷ Daily Onsited.

    Finished LT = an LT where every leg has a dest_ata; LTs still on the road are left out of the next three measures, since they'd look empty or too short. Empty LT = a finished LT whose pickup and delivery legs were all empty: every FM Hub → SOC leg arrived at the SOC carrying 0 parcels, and every SOC → LM Hub leg left the SOC with 0 loaded (total_loaded; blank counts as 0). SOC → FM and LM → SOC legs are ignored, since they normally run empty. Working Hrs = last leg's dest_ata − first leg's trip_ata, i.e. from the truck arriving at its first station to arriving at its final destination. Working Hrs per Onsited Unit = total working hours ÷ Daily Onsited.

    4. Empty pickup & delivery legs (0 parcels) — which SOCs drive them

    Covers every cost type (In-House, By Day, By Month, By Trip, By Weight), not only DR, and every finished LT including FM pickup routes that start at a hub. Only legs that should carry parcels are checked: FM Hub → SOC (pickup coming in; the SOC is the destination) and SOC → LM Hub (delivery going out; the SOC is the origin). SOC → FM and LM → SOC legs are ignored, since they normally run empty. An FM → SOC leg is empty when the truck arrives at the SOC carrying 0 parcels: nothing loaded at any hub since it last left a SOC (so a multi-stop pickup whose last FM hub had nothing isn't empty if earlier stops gave parcels). A SOC → LM leg is empty when 0 parcels were loaded at the SOC. total_loaded blank counts as 0. Empty rate = empty legs ÷ all legs of that direction at that SOC. Follows the Date Window. Click a SOC to list only its empty legs below.

    Ordered DR vs Onsited DR, by Origin DC & Vehicle Type — per Day

    Each cell reads Ordered / Onsited. Ordered = units booked on the DR order sheet whose contract window (Start–End date) covers that day. Onsited = distinct vehicles (deduped by Nopol + Vendor) that checked in ("By Day", excl. Expired/No Show) at that DC on that specific day. The order sheet only has two coarse categories, CDD L and WB; WB is mapped to the onsite system's TRONTON (10WH) record, and CDD L covers every other Vehicle Type recorded onsite. The Campaign-to-date column sums Onsited across days, so it can exceed the campaign-to-date Ordered count.
